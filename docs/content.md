Every Markdown or MDX file starts with YAML frontmatter containing a stable `id` and `title`. IDs are independent of file locations. The canonical identity is `source-id::document-id`; preserve it when moving a page. Unknown fields and duplicate YAML keys fail validation. Use [the generated frontmatter reference](doc:schema-reference) for optional fields and types.

```markdown
---
id: first-steps
title: First steps
tags: [guide]
relationships:
  - type: related
    target: overview
---

Read the [overview](doc:overview) or its [setup section](doc:overview#setup).

::doc-embed{ref="shared::instructions#setup" headingOffset="1" includeTitle="false"}
```

An unqualified reference first resolves within its own source, then across sources if exactly one match exists. Qualified references select one source. Ambiguous references list the candidates. Heading fragments are validated after embed expansion. Ordinary relative document links work but warn because file moves can break them.

## Relationships

Configure relationship type IDs and labels in YAML. An optional `inverse` names an existing type; self-inverse types are allowed. The renderer derives reverse edges and deduplicates authored reciprocals. These edges affect page panels, not navigation or audience access. Each projection hides relationships to invisible targets.

## Embeds

Place `::doc-embed` on its own block. Without a fragment it includes the target body; with a fragment it includes that heading and its subtree, ending at the next heading of equal or lower level. Nested embeds retain the owning source for assets and links. Target frontmatter never becomes host frontmatter.

`includeTitle` defaults to false. `headingOffset` defaults to zero. Heading depths above six are clamped with a warning. Duplicate heading IDs either receive `embed-<target-id>-` prefixes and rewritten local links, or fail under `embeds.duplicateHeadingIds: error`. Cycles fail with their active path; `embeds.maxDepth` limits recursion. Embedded diagnostics retain the original source location and host stack.

MDX imports and components are compiled by Astro. Statically analyzable Markdown headings and logical links are still validated. Embed targets requiring module-scope MDX declarations are unsupported and fail clearly. Dynamic expressions in directive attributes are unsupported. MDX, imported components, extensions, and raw HTML are trusted author inputs; raw HTML is not sanitized.

## Visibility, drafts, and search

Omitted audience metadata means all audiences. Explicit audiences are flat labels, validated against configuration. An embed is visible only at the intersection of host, target, directive, and active projection audiences. Restricted embeds produce an informational review diagnostic and contribute no hidden text or headings.

Drafts appear in development unless `--exclude-drafts` is set. Production builds and search omit drafts. `nav.hidden` removes a page from autogenerated navigation while leaving its route and search intact. `search.exclude` leaves the page visible but removes its search record. Search indexes title, description, tags, allowed headings, and optionally body text. Code blocks, navigation chrome, redirects, and relationship panels are excluded. Set `search.indexEmbeds: false` to exclude embedded headings and text from the host’s index.

## Navigation and URLs

Explicit navigation uses logical `doc` references, nested `group` items, external or site-relative `link` items, and `autogenerate` source/directory selections. Empty audience-filtered groups disappear. Autogenerated siblings sort by order, then label/title, then canonical key. `nav.group` labels the immediate source directory; conflicting labels fail. Strict navigation warns about omitted visible pages. Native Starlight sidebar configuration is allowed when doc-base navigation is absent, with a warning about audience guarantees.

Derived routes use source-relative paths and remove a terminal index segment. `slug` replaces that derived path; `routePrefix` and `site.baseUrl` are then applied once. Routes are normalized and encoded, with portable case/Unicode collision checks. `site.trailingSlash` applies to every canonical URL; ignore preserves the authored file/directory style. Reserved output prefixes cannot be document routes.

Relative assets resolve within their owning source root, including for embedded content. Missing assets and path escapes fail. Assets are copied with content fingerprints. Record former public URLs in `redirects` when changing a slug or moving a file; redirects point directly to the current page and cannot shadow another page or reserved asset path.
