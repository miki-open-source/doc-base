Configuration uses `doc-base.yaml`. The canonical schema is <https://doc-base.dev/schemas/v1/doc-base.schema.json>; the frontmatter schema is <https://doc-base.dev/schemas/v1/frontmatter.schema.json>. Run `doc-base schema config` or `doc-base schema frontmatter` to print the installed contracts.

Precedence is defaults, project YAML, `.doc-base/local.yaml`, documented environment variables, then flags. The local overlay permits source paths/refs, output/cache directories, and development host/port/open. Gitignore the local overlay.

## Sources

Local sources declare `type: local` and `path`. Git sources declare `type: git`, `repository`, and `ref`. Content selects a directory beneath the source root. Included Markdown and MDX paths use picomatch globs. Escaping symlinks are rejected.

Commit `.doc-base/sources.lock.json`. Use `--frozen-lockfile` in CI and `--offline` when every required Git checkout is cached. `--refresh` cannot combine with offline mode. Git uses existing credential helpers; never put tokens in committed configuration.

## Content

Frontmatter supports description, slug, audiences, tags, order, nav, relationships, redirects, search, metadata, validation, and draft. Unknown fields fail. IDs resolve in the same source first, then globally if unique; `source::id` selects an exact source.

A standalone `::doc-embed{ref="document-id"}` embeds a document. A `#heading` fragment selects a section. Attributes include `headingOffset`, `includeTitle`, and comma-separated `audiences`. Embedded content is visible only at the intersection of host, target, and directive audiences.

## Publishing

The default audience uses the base URL; other audiences use `_audience/<id>/`. `--audience` builds just one projection at the base. Navigation and search follow each projection. `nav.hidden` affects autogenerated navigation only; `search.exclude` affects search only.

Paths derive routes unless slug overrides them. Old paths require explicit redirects. Relative assets resolve against their source document, including inside embeds.
